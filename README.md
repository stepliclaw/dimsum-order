# 點心點餐系統 (Dimsum Order)

一個專為長者設計的手機點餐系統，讓顧客可以輕鬆瀏覽及揀選點心。

## 專案簡介

點心點餐系統是一個示範性的手機應用程式，旨在幫助長者學習使用數碼點餐系統。系統提供簡潔易用的介面，支援中英文切換，讓顧客可以輕鬆瀏覽點心菜單、選擇心儀的點心，以及查看訂單記錄。

## 主要功能

### 🥟 瀏覽點心菜單

- 顯示所有可用的點心項目，包括名稱、照片、價格和描述
- 支援分類篩選功能，方便快速找到想要的點心
- 即時計算訂單總價

### 🛒 訂購功能

- 將點心加入訂單，並可調整數量
- 支援分層定價（小點/中點/大點/特點）及固定港幣定價
- 提交訂單並獲得訂單確認

### 📋 訂單記錄

- 查看所有已提交的訂單
- 顯示訂單詳情，包括項目、數量、價格和提交時間
- 支援一鍵重新下單功能

### 🌐 多語言支援

- 支援英文及繁體中文
- 可隨時切換語言
- 介面文字清晰易讀，適合長者使用

## 技術架構

### 前端技術

- **框架**: Next.js 14 (React 18)
- **程式語言**: TypeScript 5.x
- **樣式**: TailwindCSS + Shadcn/ui
- **狀態管理**: Zustand
- **國際化**: i18next

### 開發工具

- **程式碼檢查**: ESLint
- **程式碼格式化**: Prettier
- **Git Hooks**: Husky + lint-staged
- **套件管理**: pnpm

## 快速開始

### 環境需求

- Node.js 18.17 或以上版本
- pnpm 10.30.3 或以上版本

### 安裝步驟

1. 複製專案

```bash
git clone <repository-url>
cd dimsum-order
```

2. 安裝相依套件

```bash
pnpm install
```

3. 啟動開發伺服器

```bash
pnpm dev
```

4. 開啟瀏覽器訪問 `http://localhost:3000`

### 其他指令

- **建置生產版本**: `pnpm build`
- **啟動生產伺服器**: `pnpm start`
- **程式碼檢查**: `pnpm lint`
- **程式碼格式化**: `pnpm format`
- **執行測試**: `pnpm test`

## 菜單管理

菜單項目儲存於 `public/menu.json`，可由工作人員直接編輯。每個項目包含：

- 名稱（英文及中文）
- 描述
- 圖片
- 價格類型（分層或固定）
- 分類

## 定價模式

系統支援兩種定價方式：

1. **分層定價**: 小點 / 中點 / 大點 / 特點
2. **固定定價**: 以港幣顯示具體價格
